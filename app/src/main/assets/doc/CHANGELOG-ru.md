# История выпусков

## v1.1.0

###### 2026/08/31

* `Функция` Добавлены структура документа, поиск по странице, сохраняемый масштаб текста и подсветка синтаксиса при рендеринге без включения JavaScript
* `Функция` Добавлен безопасный переход к относительным Markdown-документам внутри разрешенного хостом каталога с историей просмотрщика и обработкой якорей
* `Функция` Добавлены печать Android / экспорт PDF и ограниченное отображение YAML front matter
* `Функция` Добавлены определяемые и встроенные Footnotes с очищенными двунаправленными обратными ссылками
* `Улучшение` Усилена проверка explorer-action v1 Intent, URI, путей, ссылок, ресурсов, HTML и Footnotes с сохранением границы одного файла только для чтения
* `Улучшение` Добавлены отмечаемая Roadmap, 4 снимка реального устройства только с синтетическими данными и воспроизводимая генерация README / CHANGELOG для 10 языков
* `Зависимость` CommonMark перенесен со старого fork Atlassian 0.9.0 на официальные модули core и расширения 0.30.0 из Maven Central, а core library desugaring сохраняет совместимость с API 24

## v1.0.1

###### 2026/08/08

* `Исправление` Ошибка включения плагина в центре плагинов AutoJs6 из-за возврата службой пустой привязки (onNullBinding)
* `Улучшение` Упрощены название и описание плагина, унифицированы формулировки пользовательской документации на всех языках

## v1.0.0

###### 2026/08/06

* `Функция` Первый выпуск Markdown Previewer: действие `Предпросмотр Markdown` в дополнительном меню файлового менеджера AutoJs6, отображающее один документ только для чтения
* `Функция` Распознавание 10 расширений (md / markdown / mdown / mkd / mkdn / mdwn / mdtext / mdtxt / rmd / qmd) и MIME-типов `text/markdown` и `text/x-markdown`
* `Функция` Отрисовка таблиц, списков задач, зачеркивания, автоматических ссылок, якорей заголовков и изображений в документе
* `Функция` Темы GitHub (Авто / светлая / темная), Бумага и Сепия, импорт пользовательского CSS, ручное обновление и полноэкранный режим
* `Функция` Песочница только для чтения: очистка по списку разрешенного, ограничения CSP, отключенные JavaScript и хранилище, фильтрация частных адресов и лимиты ввода (Markdown 8 MiB, CSS 256 KiB)
* `Функция` Регистрация службы плагина по протоколу `org.autojs.plugin.EXPLORER_ACTION` и доступ к выбранному файлу и его родительскому каталогу через временные content URI, выданные хостом
* `Функция` Локализация сведений о плагине, интерфейса, инструкций и документации на упрощенный китайский, традиционный китайский (Гонконг / Тайвань), английский, французский, испанский, японский, корейский, русский и арабский
