Markdown Previewer는 AutoJs6 안에서 Markdown 문서를 서식이 적용된 화면으로 미리 봅니다. 표, 작업 목록, 각주, 코드 강조를 지원하며 문서 개요, 페이지에서 찾기, 여러 미리보기 테마, PDF 내보내기도 제공합니다. 미리보기는 파일을 읽기만 하며 원본 파일을 수정하지 않습니다.

### 시작하기

1. AutoJs6의 "플러그인 센터"에서 이 플러그인이 활성화되어 있는지 확인합니다.
2. AutoJs6 파일 관리자를 열고 Markdown 파일을 찾습니다.
3. 파일 메뉴에서 "Markdown 미리보기"를 선택합니다 (AutoJs6 6.8.1 이상에서는 최상위 메뉴 "Markdown Previewer" 아래에 있습니다).
4. 미리보기 화면 오른쪽 위의 메뉴에서 찾기, 개요, 테마, PDF 내보내기, "설정" 등을 사용합니다.

### 주요 기능

- **페이지에서 찾기**: 입력한 텍스트와 일치하는 부분을 강조 표시하고, 일치 항목 사이를 이동할 수 있습니다.
- **문서 개요**: 문서의 제목을 수준별로 나열하며, 하나를 탭하면 해당 위치로 이동합니다.
- **미리보기 테마**: "미리보기 테마"에서 "GitHub (자동)", "GitHub 라이트", "GitHub 다크", "종이", "세피아" 중에서 고릅니다. "GitHub (자동)"은 AutoJs6의 다크 모드를 따릅니다.
- **사용자 지정 CSS**: "사용자 지정 CSS 가져오기"로 256 KiB 이하의 스타일시트를 선택하면 미리보기가 "사용자 지정 CSS" 테마로 바뀝니다. "사용자 지정 CSS 지우기"를 선택하면 "GitHub (자동)"으로 돌아갑니다.
- **인쇄와 PDF 내보내기**: "인쇄 / PDF 내보내기"는 시스템 인쇄 화면을 열어 인쇄하거나 PDF로 저장할 수 있게 합니다. 플러그인에는 저장소 권한이 필요하지 않습니다.
- **확장 문법**: 표, 취소선, 작업 목록, 각주, 자동 링크, 코드 강조를 지원합니다. 문서 첫머리의 YAML 메타데이터는 펼칠 수 있는 "YAML 메타데이터" 블록에 표시됩니다.
- **링크와 이미지**: 같은 폴더나 그 하위 폴더의 Markdown 파일을 가리키는 링크는 미리보기 안에서 열리고, 웹 링크는 브라우저에서 열립니다. 문서가 있는 폴더의 이미지와 HTTPS 이미지를 표시합니다.
- **글자 크기와 전체 화면**: "설정"에서 "글자 크기"를 조절하고, 필요하면 "전체 화면 모드로 시작"을 켭니다. "전체 화면 모드"는 도구 모음과 시스템 표시줄을 숨기며, 뒤로 키로 나갈 수 있습니다.

### 요구 사항

- Android 7.0 이상.
- AutoJs6 6.8.0 이상.
- 저장소 권한이 필요하지 않습니다. 플러그인은 선택한 파일과 그 폴더만 읽으며, 네트워크는 문서의 HTTPS 이미지를 불러올 때만 사용합니다.

### 자주 묻는 질문

**파일 메뉴에 "Markdown 미리보기"가 없는 이유**

이 플러그인은 확장자가 md, markdown, mdown, mkd, mkdn, mdwn, mdtext, mdtxt, rmd, qmd인 파일만 처리합니다. 파일 확장자를 확인하고, "플러그인 센터"에서 이 플러그인이 활성화되어 있는지 확인하세요.

**일부 이미지가 표시되지 않는 이유**

로컬 이미지는 Markdown 파일이 있는 폴더나 그 하위 폴더에 있어야 합니다. 네트워크 이미지는 공개된 HTTPS 주소만 지원하며, HTTP와 로컬 네트워크 주소는 불러오지 않습니다.

**파일이 미리보기 한도를 넘는다고 표시되는 이유**

8 MiB를 넘는 Markdown 파일은 미리 보지 않습니다. 문서를 몇 개의 작은 파일로 나누고 링크로 서로 연결하세요.

**HTML 파일을 미리 보는 방법**

이 플러그인은 Markdown 문서만 미리 봅니다. HTML과 MHTML 파일은 [HTML Previewer](https://github.com/SuperMonster003/AutoJs6-Plugin-HTML-Previewer) 플러그인을 사용하세요.

자세한 내용은 [프로젝트 페이지](https://github.com/SuperMonster003/AutoJs6-Plugin-Markdown-Previewer)를 참고하세요.
