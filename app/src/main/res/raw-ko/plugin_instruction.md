파일 관리자에서 Markdown Previewer를 사용합니다:

1. `Markdown Previewer` 플러그인을 설치하고 활성화합니다.
2. 지원되는 Markdown 파일의 더보기 메뉴를 엽니다.
3. `Markdown 미리보기`를 선택합니다.

플러그인은 content URI를 통해 선택한 파일과 상위 디렉터리에 대한 임시 읽기 권한을 받습니다. 원시 파일 시스템 경로는 받지 않습니다.

지원 확장자: `md`, `markdown`, `mdown`, `mkd`, `mkdn`, `mdwn`, `mdtext`, `mdtxt`, `rmd`, `qmd`.

뷰어는 자동 링크, 표, 취소선, 제목 앵커, 작업 목록, 문서 내 이미지, 기본 제공 테마, 사용자 지정 CSS, 새로 고침, 전체 화면 모드를 지원합니다.

버전 1은 파일 관리자의 단일 파일 읽기 전용 작업만 지원합니다.

Explorer Action v2는 단일 파일의 기본 미리보기 버튼과 메뉴를 지원하며 문서와 상위 폴더의 임시 읽기 권한을 사용합니다. AutoJs6 빌드 5269 이상이 필요합니다.

메뉴와 대화상자는 AutoJs6 언어와 다크 모드를 따릅니다. GitHub (Auto)와 HTML 자동 테마도 동일합니다. 도구 모음과 시스템 표시줄은 렌더링 영역 가장자리의 대표색과 대비되는 검정 또는 흰색 글자 및 아이콘을 사용합니다. 그라데이션, 이미지, 애니메이션에서는 다시 로드할 때까지 색을 고정하여 깜박임을 방지합니다.
