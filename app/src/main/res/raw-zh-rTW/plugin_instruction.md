Markdown Previewer 在 AutoJs6 中按排版效果預覽 Markdown 文件, 支援表格, 工作清單, 註腳與程式碼醒目標示, 並提供文件大綱, 頁內尋找, 多種預覽主題與匯出 PDF. 預覽全程唯讀, 不修改原始檔案.

### 開始使用

1. 在 AutoJs6 的 "外掛中心" 中確認本外掛已啟用.
2. 開啟 AutoJs6 的檔案管理器, 找到要預覽的 Markdown 檔案.
3. 在檔案選單中選擇 "預覽 Markdown" (AutoJs6 6.8.1 或更新版本中位於第一層選單 "Markdown Previewer" 之下).
4. 在預覽頁右上角的選單中使用尋找, 大綱, 主題, 匯出 PDF 與 "設定" 等功能.

### 主要功能

- **在頁面中尋找**: 輸入關鍵字後醒目標示相符項目, 並可在相符項目之間跳轉.
- **文件大綱**: 依層級列出文件中的標題, 輕觸即可跳到對應位置.
- **預覽主題**: 在 "預覽主題" 中選擇 "GitHub (自動)", "GitHub 淺色", "GitHub 深色", "紙張" 或 "棕褐色"; "GitHub (自動)" 跟隨 AutoJs6 的深色模式.
- **自訂 CSS**: 用 "匯入自訂 CSS" 選擇不超過 256 KiB 的樣式檔案後, 預覽會切換到 "自訂 CSS" 主題; 選擇 "清除自訂 CSS" 即恢復 "GitHub (自動)".
- **列印與匯出 PDF**: "列印 / 匯出 PDF" 開啟系統列印介面, 可以列印或另存為 PDF; 外掛不需要儲存空間權限.
- **擴充語法**: 支援表格, 刪除線, 工作清單, 註腳, 自動連結與程式碼醒目標示; 文件開頭的 YAML 中繼資料顯示在可展開的 "YAML 中繼資料" 區塊中.
- **連結與圖片**: 指向同一目錄或其子目錄中 Markdown 檔案的連結會在預覽器內開啟, 網頁連結交給瀏覽器; 可顯示文件所在目錄中的圖片與 HTTPS 圖片.
- **字體大小與全螢幕**: 在 "設定" 中調整 "字體大小", 也可開啟 "以全螢幕模式啟動"; "全螢幕模式" 隱藏工具列與系統列, 按返回鍵退出.

### 執行需求

- Android 7.0 或更新版本.
- AutoJs6 6.8.0 或更新版本.
- 不需要儲存空間權限; 外掛只讀取所選檔案及其所在目錄, 網路只用於載入文件中的 HTTPS 圖片.

### 常見問題

**檔案選單中沒有 "預覽 Markdown" 的原因**

本外掛只處理副檔名為 md, markdown, mdown, mkd, mkdn, mdwn, mdtext, mdtxt, rmd, qmd 的檔案. 請確認檔案的副檔名, 並在 "外掛中心" 中確認本外掛已啟用.

**部分圖片沒有顯示的原因**

本機圖片需要位於 Markdown 檔案所在的目錄或其子目錄中. 網路圖片只支援公用網路的 HTTPS 網址, HTTP 與區域網路網址不會載入.

**提示檔案超過預覽限制的原因**

超過 8 MiB 的 Markdown 檔案不會預覽. 可以把文件拆分成幾個較小的檔案, 再用連結互相跳轉.

**HTML 檔案的預覽方式**

本外掛只預覽 Markdown 文件. 預覽 HTML 與 MHTML 檔案請使用 [HTML Previewer](https://github.com/SuperMonster003/AutoJs6-Plugin-HTML-Previewer) 外掛.
