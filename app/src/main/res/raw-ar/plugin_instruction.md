استخدم Markdown Previewer من مدير الملفات:

1. ثبت المكون `Markdown Previewer` وقم بتمكينه.
2. افتح القائمة الإضافية لملف Markdown مدعوم.
3. اختر `معاينة Markdown`.

يتلقى المكون إذن قراءة مؤقتا للملف المحدد والمجلد الأصل عبر content URI. لا يتلقى مسارا خاما لنظام الملفات.

الامتدادات المدعومة: `md`, `markdown`, `mdown`, `mkd`, `mkdn`, `mdwn`, `mdtext`, `mdtxt`, `rmd`, `qmd`.

يدعم العارض الروابط التلقائية والجداول والنص المشطوب ومراسي العناوين وقوائم المهام والصور داخل المستند والسمات المدمجة و CSS المخصص والتحديث ووضع ملء الشاشة.

يدعم Explorer Action v2 زر العرض الرئيسي وقائمة الملف الواحد مع إذن قراءة مؤقت للمستند والمجلد الأب. يلزم AutoJs6 بالإصدار الداخلي 5269 أو أحدث.
