Используйте Markdown Previewer в файловом менеджере:

1. Установите и включите плагин `Markdown Previewer`.
2. Откройте дополнительное меню поддерживаемого файла Markdown.
3. Выберите `Предпросмотр Markdown`.

Плагин получает временный доступ на чтение выбранного файла и его родительского каталога через URI содержимого. Он не получает исходный путь файловой системы.

Поддерживаемые расширения: `md`, `markdown`, `mdown`, `mkd`, `mkdn`, `mdwn`, `mdtext`, `mdtxt`, `rmd`, `qmd`.

Средство просмотра поддерживает автоматические ссылки, таблицы, зачеркивание, якоря заголовков, списки задач, изображения в документе, встроенные темы, пользовательский CSS, обновление и полноэкранный режим.

Explorer Action v2 поддерживает основную кнопку и контекстное меню одного файла с временным доступом на чтение документа и родительского каталога. Требуется AutoJs6 build 5269 или новее.
