Markdown Previewer は, AutoJs6 の中で Markdown ドキュメントを整形された表示でプレビューします. 表, タスクリスト, 脚注, コードのハイライトに対応し, ドキュメントのアウトライン, ページ内検索, 複数のプレビューテーマ, PDF へのエクスポートも使えます. プレビューは読み取りのみで, 元のファイルは変更しません.

### はじめに

1. AutoJs6 の "プラグインセンター" で本プラグインが有効になっていることを確認します.
2. AutoJs6 のファイルマネージャーを開き, Markdown ファイルを探します.
3. ファイルメニューから "Markdown をプレビュー" を選びます (AutoJs6 6.8.1 以降では最上位メニュー "Markdown Previewer" の中にあります).
4. プレビュー画面右上のメニューから, 検索, アウトライン, テーマ, PDF のエクスポート, "設定" などを使います.

### 主な機能

- **ページ内検索**: 入力した語句に一致する箇所を強調表示し, 一致箇所の間を移動できます.
- **ドキュメントのアウトライン**: ドキュメントの見出しを階層ごとに一覧表示し, タップするとその位置へ移動します.
- **プレビューテーマ**: "プレビューテーマ" で "GitHub (自動)", "GitHub ライト", "GitHub ダーク", "ペーパー", "セピア" から選びます. "GitHub (自動)" は AutoJs6 のダークモードに従います.
- **カスタム CSS**: "カスタム CSS をインポート" で 256 KiB 以下のスタイルシートを選ぶと, プレビューが "カスタム CSS" テーマに切り替わります. "カスタム CSS を消去" を選ぶと "GitHub (自動)" に戻ります.
- **印刷と PDF のエクスポート**: "印刷 / PDF にエクスポート" でシステムの印刷画面を開き, 印刷するか PDF として保存できます. プラグインにストレージの権限は不要です.
- **拡張構文**: 表, 取り消し線, タスクリスト, 脚注, 自動リンク, コードのハイライトに対応します. ドキュメント先頭の YAML メタデータは, 展開できる "YAML メタデータ" ブロックに表示されます.
- **リンクと画像**: 同じフォルダーかそのサブフォルダーにある Markdown ファイルへのリンクはプレビューの中で開き, Web リンクはブラウザーで開きます. ドキュメントと同じフォルダーの画像と HTTPS の画像を表示できます.
- **文字サイズと全画面**: "設定" で "文字サイズ" を調整し, 必要なら "全画面モードで開始" をオンにします. "全画面モード" はツールバーとシステムバーを隠し, 戻るキーで終了します.

### 動作要件

- Android 7.0 以降.
- AutoJs6 6.8.0 以降.
- ストレージの権限は不要です. プラグインは選んだファイルとそのフォルダーだけを読み取り, ネットワークはドキュメント内の HTTPS 画像を読み込むときだけ使います.

### よくある質問

**ファイルメニューに "Markdown をプレビュー" がない理由**

本プラグインが扱うのは拡張子が md, markdown, mdown, mkd, mkdn, mdwn, mdtext, mdtxt, rmd, qmd のファイルだけです. ファイルの拡張子を確認し, "プラグインセンター" で本プラグインが有効になっていることを確認してください.

**一部の画像が表示されない理由**

ローカルの画像は, Markdown ファイルと同じフォルダーかそのサブフォルダーに置く必要があります. ネットワーク画像は公開された HTTPS のアドレスだけに対応し, HTTP やローカルネットワークのアドレスは読み込みません.

**ファイルがプレビューの上限を超えると表示される理由**

8 MiB を超える Markdown ファイルはプレビューしません. ドキュメントをいくつかの小さなファイルに分け, リンクでつないでください.

**HTML ファイルをプレビューする方法**

本プラグインがプレビューするのは Markdown ドキュメントだけです. HTML と MHTML ファイルには [HTML Previewer](https://github.com/SuperMonster003/AutoJs6-Plugin-HTML-Previewer) プラグインを使ってください.

詳しくは [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-Markdown-Previewer) をご覧ください.
