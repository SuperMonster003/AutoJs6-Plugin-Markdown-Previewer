AutoJs6 のメインエクスプローラーで Markdown Preview を使用します:

1. `Markdown Preview` プラグインをインストールして有効にします.
2. 対応する Markdown ファイルのオーバーフローメニューを開きます.
3. `Markdown をプレビュー` を選択します.

プラグインは content URI を通じて選択したファイルと親ディレクトリの一時読み取り権限を受け取ります. 生のファイルシステムパスは受け取りません.

対応拡張子: `md`, `markdown`, `mdown`, `mkd`, `mkdn`, `mdwn`, `mdtext`, `mdtxt`, `rmd`, `qmd`.

ビューアーは自動リンク, 表, 取り消し線, 見出しアンカー, タスクリスト, 文書内画像, 組み込みテーマ, カスタム CSS, 再読み込み, 全画面モードをサポートします.

バージョン 1 は AutoJs6 のメインエクスプローラーにある単一ファイル用の読み取り専用アクションのみをサポートします.
