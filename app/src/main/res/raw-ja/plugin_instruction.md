ファイルマネージャーで Markdown Previewer を使用します:

1. `Markdown Previewer` プラグインをインストールして有効にします.
2. 対応する Markdown ファイルのオーバーフローメニューを開きます.
3. `Markdown をプレビュー` を選択します.

プラグインは content URI を通じて選択したファイルと親ディレクトリの一時読み取り権限を受け取ります. 生のファイルシステムパスは受け取りません.

対応拡張子: `md`, `markdown`, `mdown`, `mkd`, `mkdn`, `mdwn`, `mdtext`, `mdtxt`, `rmd`, `qmd`.

ビューアーは自動リンク, 表, 取り消し線, 見出しアンカー, タスクリスト, 文書内画像, 組み込みテーマ, カスタム CSS, 再読み込み, 全画面モードをサポートします.

バージョン 1 はファイルマネージャーにある単一ファイル用の読み取り専用アクションのみをサポートします.

Explorer Action v2 は単一ファイルのメインプレビューボタンとメニューに対応し, 文書と親ディレクトリへの一時的な読み取り権限を使用します. AutoJs6 ビルド 5269 以降が必要です.

メニューとダイアログは AutoJs6 の言語とダークモードに従います. GitHub (Auto) と HTML 自動テーマも同様です. ツールバーとシステムバーには描画領域の端から取得した代表色を使い, 文字とアイコンは対比のある黒または白にします. グラデーション, 画像, アニメーションでは再読み込みまで色を固定してちらつきを防ぎます.
